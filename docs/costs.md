# ARC — Running costs

**Short answer: the whole ARC stack can run at $0/month** on Oracle Cloud's Always Free tier, with
free model-provider tiers and a free email account for alerts. The only optional cost is a
domain name (≈ $10/year); a free subdomain (e.g. DuckDNS) works too.

Limits change: check each provider's page before relying on a number below (checked
November 2026).

| Piece            | Free option                                                                                                          | What it covers                                                       | Watch out for                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Server           | Oracle Cloud **Always Free** Ampere A1 (Arm) VM                                                                      | Postgres, Redis, LiteLLM, ARC API + worker, Prometheus, Alertmanager | The A1 allowance was 4 OCPU / 24 GB; a July 2026 report says Oracle cut it to **2 OCPU / 12 GB** — check the console. ARC fits either way; on 2 OCPU set `LITELLM_NUM_WORKERS=2` and re-run `scripts/ops/vps-verify.sh`. Oracle may reclaim an Always Free VM it considers idle (95th-percentile CPU, network and memory all under 20 % for 7 days). Upgrading the account to Pay-As-You-Go stops idle reclamation while Always Free resources stay free — set a **budget alert at $1** so nothing paid can surprise you. |
| Disk             | 200 GB block storage (boot + data)                                                                                   | OS, Docker images, database, local backups                           | Create volumes in the home region.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Off-site backups | Oracle Object Storage, 20 GB free                                                                                    | Encrypted nightly dumps (`BACKUP_RCLONE_REMOTE`)                     | ARC's dumps are KBs–MBs; 14-day retention stays far below 20 GB.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Models           | Free tiers: Gemini (AI Studio), Groq, Cerebras, OpenRouter `:free` models, Mistral, … ([providers.md](providers.md)) | All app traffic                                                      | Free tiers have per-minute and per-day limits. ## What could cost money

- **A paid model**: only if you mark a model `PAID` _and_ turn on `allowPaidOwnerKeys` for a
  tenant or app. Off by default.
- **Leaving Always Free shapes**: e.g. picking an AMD/Intel VM shape or more than the free A1
  allowance. The budget alert catches this.
- **Egress** beyond Oracle's free 10 TB/month — far above what ARC sends.
